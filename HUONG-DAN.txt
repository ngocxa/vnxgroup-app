APP VNXGROUP – HƯỚNG DẪN TẠO FILE CÀI ĐẶT ANDROID (.APK)

A. TẢI MÃ NGUỒN LÊN GITHUB (kho vnxgroup-app)
1. Giải nén file vnxgroup-app.zip.
2. Vào https://github.com/ngocxa/vnxgroup-app > Add file > Upload files.
3. Kéo thả: index.html, manifest.json, sw.js, HUONG-DAN.txt, thư mục icons
   và thư mục android > bấm Commit changes.

B. TẠO "MÁY ĐÓNG GÓI" (chỉ làm 1 lần)
1. Trong kho, bấm Add file > Create new file.
2. Ô tên file gõ đúng:   .github/workflows/build-apk.yml
3. Mở file build-apk.yml (trong thư mục .github/workflows đã giải nén),
   chép toàn bộ nội dung, dán vào ô soạn thảo > bấm Commit changes.
   (Thư mục .github là thư mục ẩn; nếu không thấy, bật "Hiện tệp ẩn".)

C. LẤY FILE APK
1. Bấm tab Actions > sẽ thấy "Build Android APK" đang chạy (vòng vàng).
   Nếu GitHub hỏi, bấm "I understand my workflows, go ahead and enable them".
   Nếu chưa chạy: chọn Build Android APK > Run workflow > Run workflow.
2. Đợi khoảng 3–5 phút đến khi hiện dấu tích xanh ✓.
3. Link tải app (cố định, gửi cho mọi người):
   https://github.com/ngocxa/vnxgroup-app/releases/latest/download/VNXGroup.apk

D. CÀI APP TRÊN ĐIỆN THOẠI ANDROID
- Mở link trên bằng Chrome > Tải xuống > Mở file VNXGroup.apk.
- Máy hỏi "Cho phép cài từ nguồn này" > bật > quay lại > Cài đặt.
- Nếu Play Protect cảnh báo: chọn "Chi tiết khác" > "Vẫn cài đặt".
- Biểu tượng logo VNX xuất hiện trên màn hình chính như mọi app khác.
- Lần đầu mở app, bấm "Cho phép" thông báo để được nhắc giờ kinh 19:35.

E. CẬP NHẬT
- Nội dung app (bài viết, giao diện) lấy trực tiếp từ web nên tự cập nhật,
  KHÔNG cần cài lại.
- Chỉ khi sửa thư mục android, GitHub sẽ tự đóng gói bản APK mới.

iPhone: Apple không cho cài file ngoài App Store, nên trên iPhone dùng
cách "Thêm vào MH chính" trong Safari (app vẫn có biểu tượng logo VNX).

LƯU Ý: Giữ nguyên file android/app/vnxgroup.keystore (khóa ký app).
Mất file này thì các bản cập nhật sau sẽ không cài đè lên bản cũ được.
