Giới hạn bản dùng thử: watermark "BẢN DÙNG THỬ", không In, không xuất Word/Excel/PDF, không sao chép văn bản dài. Vẫn sao lưu dữ liệu (.json) được.
Dữ liệu mẫu dùng tên giả (Trạm Y tế / Trung tâm Y tế An Bình).

## Tạo lại bản demo khi phần mềm có phiên bản mới
```
python3 demo/build/build_demo.py <ChamCong.html> <SoanThao_ND30.html> <QuanLyVienChuc.html> <thu_muc_ra>
```
Rồi chép 3 file .zip trong thư mục ra vào `demo/`. Link tải trong bài blog (`/raw/main/demo/...zip`) tự dùng bản mới.
